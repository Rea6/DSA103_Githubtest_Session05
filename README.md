# DSA103 GitHub Test Session 05

This project contains a minimal Python package and a greeting example for the GitHub/version-control exercise.

## Features

- A reusable `greetings(name: str) -> str` function.
- A package-level `main()` entry point compatible with the project script.
- A module entry point for `python -m dsa103_githubtest_session05`.

## Run locally

From the project root:

```bash
python -m pip install -e .
python -m dsa103_githubtest_session05
```

You can also run the installed console script:

```bash
dsa103-githubtest-session05
```

## Example output

```text
What is your name? Ada
Hello Ada!
```
